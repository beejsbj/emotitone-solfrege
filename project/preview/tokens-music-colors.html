MUSIC COLOR RECIPE
.note {
  --note-degree: 0;            /* semitones from C (fixed) or from root (movable) */
  --note-octave: 4;            /* 0..8 */
  --note-l:   calc(20% + (var(--note-octave) * 7.5%));
  --note-hue: calc((var(--note-degree) + var(--music-rotate)) * 30deg);   /* 30° per semitone, always */
  background: oklch(var(--note-l) var(--music-c) var(--note-hue));
}
01 — Fixed Chroma C is always 0°. Each semitone = 30°. Root does nothing.
Octave row: C across octaves 0–8. Lightness 20%..80%.
02 — Movable Chroma Root rotates the palette to hue 0. Scale count drops cells. Moveable Do.
Scale grid: 7 of 12 chromatic positions. Root: C = Do.
03 — Hue Range Each chromatic cell oscillates through its 30° slice. Toggle to start.
Hue range: each semitone owns a 30° slice. Spread controls how far the cell sweeps within that slice. Respects prefers-reduced-motion.
Fixed chroma nails C to hue 0 and steps 30° per semitone, always. Movable chroma rotates the palette so the chosen root lands at hue 0 and shows only the scale-count cells — the dropped cells aren't redrawn, they're removed.
