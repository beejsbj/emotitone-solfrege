# EmotiTone Solfege Interview Prompts - Round 2

These prompts are based on the author's March 19, 2026 recollections and focus on the places where the project's deeper meaning is becoming clearer.

## 1. Voice As The Original Interface

- If the voice was the true starting instrument, what made the pad interface the next best bridge instead of, say, piano-roll style input or pitch curves?
- When you imagined humming into the app, were you imagining pitch detection as a convenience feature or as a core expression of the whole project's philosophy?
- Does the future microphone-to-Strudel idea feel like a return to the original dream, or like a new dream that only became possible later?

## 2. Solfege As Embodied Knowledge

- You said the syllables themselves felt intuitive and shaped out interval relationships. Can you remember a specific moment or exercise where solfege stopped feeling abstract and started feeling bodily obvious?
- Were there particular scale degrees that emotionally clicked first before the rest of the system did?
- Did color come after that embodied recognition, or did color help stabilize it?

## 3. The Popup Wants To Become Something Else

- If the popup moves into the LiveStrip, what exactly should be anchored there: current chord name, interval relations, semantic feeling, note stack, or some evolving sentence?
- Should that layer feel like analysis, narration, or accompaniment?
- Is the problem with the current popup mostly its position, its temporality, its name, or the fact that it still feels bolted on?

## 4. Circular Sequencer Love Versus Misfit

- You spoke about the circular sequencer with real affection. What part of it was genuinely right even if the implementation was wrong?
- Was the disconnection from the keyboard mainly a UX bug, or did it reveal that the sequencing model itself was detached from how you wanted to think and play?
- If you brought back the record-player visual later, would it be for editing, playback visualization, or simply to preserve a part of the app's identity?

## 5. Manual Tone.js World

- You mentioned manually assembling instrument handling and musical datasets. Which pieces of that work felt educational and worthwhile, and which parts felt like pure burden?
- Did struggling through those manual systems teach you anything important that you would have missed if Strudel had appeared earlier?

## 6. The Two-Project Entanglement

- When EmotiTone and the MIDI-to-Strudel project started feeding each other, did that make this repo clearer or harder to steer?
- Were there moments where one project was carrying the experimental risk while the other carried the product vision?
- If someone read only this repo's history, what crucial piece of the pattern-system story would they miss because it really happened in the adjacent project?

## 7. Pattern System As Conversion Layer

- When you say the base unit became note-on plus note-off, was that a liberating simplification or a painful reduction?
- What were the hardest edge cases that forced the architecture to grow up?
- When did you realize that "when does a pattern switch?" was one of the central design problems?

## 8. The Near-End Feeling

- You keep saying it feels close. What is making it feel close now that did not feel true six months ago?
- Which unfinished part feels like final-mile integration, and which unfinished part still threatens the conceptual integrity of the app?
- What would make you say, without hesitation, "this is the first true version"?
