Ivory wire is the default. Brand colors (tomato / plum / pine / mustard / bone) are allowed on decoration badges — never on functional UI chrome. Stickers use shadow-cut + tilt (--rot-sticker: -2.2deg). Kicker badges pair a brand-color dot with mono label. Brass badges animate a shimmer across both the top edge and text. Geometry treatments show clip-path techniques: off-cut, paper-rip, tab-slide, and tile cuts.
