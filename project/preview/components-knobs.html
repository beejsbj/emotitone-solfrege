RANGE. Continuous 0–100. Arc fills clockwise from gap; ring fills clockwise from -135°. Numeric center.
BOOLEAN. On/off. Arc: full vs empty, ball indicator. Ring: full brass with glow vs empty.
OPTIONS. Discrete N positions. Arc: two opposing segments rotate. Ring: equal segments, active one brass.
BUTTON. Momentary trigger. Arc: 25% segment spins. Ring: brass arc spins around the perimeter.
Pick by surface. Arc reads like print — flat, hand-cut, anchors the bare ink-3 panels. Ring reads like hardware — soft inset, glows on signal, sits on app chrome. Same role API across both. Default ivory; brass once per panel, max.
