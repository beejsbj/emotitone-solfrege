Installed entrypoints are `@strudel/core` **1.2.6** and `@strudel/codemirror` **1.3.0**, both `dist/index.mjs` (`node_modules/@strudel/core/package.json:3,5`; `node_modules/@strudel/codemirror/package.json:3,5`). ## One scheduler, one separately displayed phrase

- **Cached stack replacement preserves the running cycle grid.** `stack` flattens member queries without rewriting their haps (`node_modules/@strudel/core/pattern.mjs:1321–1329`). Cyclist `setPattern` only assigns the pattern and starts if requested and stopped; it does not reset `lastEnd`. Stop explicitly resets it (`node_modules/@strudel/core/cyclist.mjs:117–135`; shipped equivalent `node_modules/@strudel/core/dist/index.mjs:3036–3044`). Scheduling queries only trigger onsets, with a default 0.1 s latency; replacing the stack does not cancel already submitted audio or retrigger a joining member's already-started note (`node_modules/@strudel/core/cyclist.mjs:17,59–75`). Phase continuity is supported by source; glitch-free joining/removal remains a device experiment.

- **Cache both pattern and compilation metadata for each exact displayed source.** Core evaluation returns `{pattern, meta}` from the transpiler; metadata includes `miniLocations`, while haps carry `context.locations` (`node_modules/@strudel/core/evaluate.mjs:41–53`; `node_modules/@strudel/transpiler/transpiler.mjs:33–59,212`). These are distinct: metadata installs editor marks, hap locations activate them. Mirror's `afterEval` installs metadata then invalidates its Drawer (`node_modules/@strudel/codemirror/codemirror.mjs:209–224`). Calling `repl.setPattern` or `scheduler.setPattern` with a cached stack does **not** run that hook (`node_modules/@strudel/core/repl.mjs:105–109,272–280`). Calling `repl.setPattern` additionally applies `editPattern` and exposes the scheduler pattern globally; direct scheduler assignment bypasses these steps.

- **Add phrase identity after each member's transformations, preserving locations:** proposed `member.withContext(ctx => ({ ...ctx, phraseId }))`, then `stack(...members)`. `withContext` maps each hap; `setContext({phraseId})` would replace its locations. `withLoc` appends ranges, and context combination can overwrite other fields while concatenating locations (`node_modules/@strudel/core/pattern.mjs:522–565`; `node_modules/@strudel/core/hap.mjs:157–161`). Identity is an adapter convention; stock highlighting does not filter it. The domain calls for stable phrase ids (`docs/pattern-system-reimagined.md:21–25`). Separately compiled phrases can have identical source offsets, so location matching alone cannot identify the desk phrase.

- **Filter before highlighting, not merely in `onDraw`.** Mirror first selects `hap.isActive(time)`, calls `this.highlight`, and only then invokes `onDraw`; its `highlight` dispatches `highlightMiniLocations` (`node_modules/@strudel/codemirror/codemirror.mjs:175–179,332–334`). Stock CodeMirror keys events solely by `start:end` and joins them to metadata-installed marks (`node_modules/@strudel/codemirror/highlight.mjs:23–40,59–69,79–96`; shipped logic `node_modules/@strudel/codemirror/dist/index.mjs:384`). Proposed adapter: intercept that highlight boundary, filter by displayed `phraseId`, dispatch to the displayed view, and install only that phrase's cached miniLocations. Use exact source offsets or remap both metadata and hap locations if display text differs. A passive view can consume these effects without owning another scheduler; the existing controlled view is already created without a REPL (`src/components/uniques/CodeStrip/index.vue:706–724`).

- **Invalidate on stack change; clear stale presentation when necessary.** Drawer incrementally retains whole haps until their clipped end and adds new onsets. `invalidate` drops future old haps, retains old haps whose whole began before now, queries `[now, now + lookahead + 0.1]`, and refreshes painters (`node_modules/@strudel/draw/draw.mjs:148–192`). Thus direct replacement needs explicit invalidation, and invalidation alone does not guarantee an immediately removed/rebuilt member disappears from highlights. Filter against current membership/version as well as desk identity, or clear/reseed the presentation cache. Metadata/document switches also need a fresh frame so old same-offset haps cannot light the new phrase. This is presentation cleanup, not cancellation of scheduled sound.

## CodeStrip timeline and follow

- The production strip generates source from the current take; `onDraw` ignores its haps and publishes global cycle time plus follow. Playback widgets receive the earlier `showMiniLocations` effect (`src/components/uniques/CodeStrip/index.vue:267–284,730–745`; `src/components/uniques/CodeStrip/strudelExtension.ts:220–250`). The extension keeps narrowest overlapping leaf locations, derives note progress from hap whole time, and tracks played ranges per loop (`src/components/uniques/CodeStrip/strudelExtension.ts:1021–1062`). It has no phrase filter.

- **Notes and rests use different clocks.** Notes use hap ranges/times; rests and played-history reset use the displayed flat grammar's total weights and `atTime`, with enclosing `[]` treated as one cycle. This deliberately does not account for arbitrary Strudel transforms (`src/components/uniques/CodeStrip/strudelExtension.ts:1065–1106`). For offset/rate members, dispatch phrase-local time `local = (globalCycles - offsetCycles) * rate` and consistently transform hap whole begin/duration into that same space (or adapt the timeline to global membership timing). Only filtering haps fixes note identity; it leaves rest progress and loop-history resets wrong. Preserve original cached source so offsets/rate need not be serialized into the displayed grammar.

- Follow selects the first active widget carrying `data-follow-rank`, positions its center at 42% of the viewport, and smooths scroll with RAF; rank is computed but the DOM query does not sort by it (`src/components/uniques/CodeStrip/index.vue:641–704`; `src/components/uniques/CodeStrip/strudelExtension.ts:329–342,1109–1113`). `followPlaybackActive` currently follows whole scheduler start/stop. A shared transport must gate desk playing/follow on that phrase's membership, including desk changes while the scheduler keeps running. Take changes currently only reset horizontal scroll (`src/components/uniques/CodeStrip/index.vue:737–750,966–973`). Recording follow is separately driven by newest note/document identity (`src/components/uniques/CodeStrip/index.vue:510–550`).

## Tempo continuity

- REPL `.cpm(x)` captures a **pattern speed multiplier** `x / 60 / scheduler.cps` at evaluation time; it does not change scheduler tempo (`node_modules/@strudel/core/repl.mjs:206–208`; shipped `node_modules/@strudel/core/dist/index.mjs:3291–3293`). The standalone core implementation assumes baseline 1 cps (`node_modules/@strudel/core/pattern.mjs:2047–2048`). Cached members compiled under differing scheduler cps therefore have differing fixed multipliers. Changing `.cpm` by rebuilding can jump member phase because it rescales absolute cycle position.

- Cyclist `setCps` keeps `lastEnd`, resetting its tempo tick counter; next tick anchors accumulated cycles at that end (`node_modules/@strudel/core/cyclist.mjs:38–50,129–135`). Source supports query-boundary continuity, not sample-perfect retiming of sounding voices or immediate continuity of every `now()` sample (`node_modules/@strudel/core/cyclist.mjs:90–95`). Normalize cached members to bar cycles, set shared cps to `bpm / 4 / 60`, and retain stable member speed multipliers; do not retain each recorded bpm as an independent `.cpm` target.

- Current CodeStrip sets scheduler cps **before** evaluation so generated `.cpm(bpm/4)` yields multiplier 1; it preserves UIBeat generation only when all source except the canonical tempo suffix matches (`src/components/uniques/CodeStrip/index.vue:286–291,319–386,775–803`). UIBeat converts raw cycles using current cps and generated bpm, rejects obsolete generations, and `retime` changes bpm without moving position (`src/composables/useUIBeat.ts:204–224,289–350`). For a shared stack, publish the shared bar position independently of the displayed phrase; the current exact-generated-document guard is insufficient to describe stack playback.

## Expression and borrowed pitch limits

- The Looper brief promises tempo-stretched expression and approximate out-of-scale mode remapping (`docs/looper.md:41–51`). Existing export provides only steady vibrato/tremolo approximations, not arbitrary bend/gain curves: `StrudelNotation` emits fixed `vib`, `vibmod`, `tremolo`, `tremolodepth` fields (`src/services/StrudelNotation.ts:137–144,322–342`). Vibrato rejects drags/jitter, requires two measured full cycles, accepts 0.25–12 Hz, and caps depth at 0.5 semitones; tremolo likewise rejects drags/constant gain and caps depth at 0.5 (`src/services/vibratoApproximation.ts:11–24,61–92`; `src/services/tremoloApproximation.ts:10–21,53–60`). Rates derive from recorded milliseconds, independent of playback bpm. Fixed articulation seconds are also emitted unchanged (`src/services/StrudelNotation.ts:194–198,345–353`). Timing weights use source bpm (`src/services/StrudelNotation.ts:66–74`); tempo changes stretch events but do not by themselves stretch those expression rates/envelopes. Exact expression bending requires an additional replay/retiming design.

- **Borrowed export fallback preserves pitch, not approximate degree bending.** Relative notation is all-or-nothing: if any note fails exact scale-degree/octave matching, the entire phrase emits absolute note names and omits `.scale` (`src/services/StrudelNotation.ts:126–127,199–208,356–376`). Applying a new scale override also participates in that exact-match check. No nearest-degree approximation is implemented there.

- **Borrowed visual fallback is separate.** Audio output is submitted first; presentation recognizes a spelled note with octave, compares it to the currently active scale, and marks out-of-scale pitches as `solfegeIndex: -1`, `isBorrowed: true`, retaining chromatic pitch and actual octave (`src/services/superdoughAudio.ts:386–402,405–479,534–554`). Visual key/mode come from current global theory, not member context; frequency alone or a numeric note cannot supply this visual payload (`src/services/superdoughAudio.ts:405–449,480–485`). Pinned members therefore need deliberate presentation context handling. This fallback does not change sounding pitch or implement mode approximation.

## Source verdict

A cached stack on one scheduler can drive one separately displayed phrase **with an adapter**: cache exact-source metadata; tag members; explicitly invalidate stack changes; filter active haps before highlight dispatch; translate phrase timeline coordinates; gate desk follow independently; publish the shared beat clock. Existing production exposes only limited scheduler typing (`src/services/patternPlayback.ts:14–25`) and owns one Mirror/audio clock (`src/services/patternPlayback.ts:52–78`). The proposed transport and CodeStrip requirement remain a spike in the brief (`docs/looper.md:83–98,115–118`); phone timing/glitch behavior is unverified by this scout.
