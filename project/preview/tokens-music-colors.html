TOKENS · MUSIC COLORS · OKLCH RECIPE
.note {
  --note-degree: 0;            /* 0..music-count-1 */
  --note-octave: 4;            /* 0..8 */
  --note-l:   calc(20% + (var(--note-octave) * 7.5%));
  --note-hue: calc((var(--note-degree) + var(--music-rotate)) * (360 / var(--music-count)));
  background: oklch(var(--note-l) var(--music-c) var(--note-hue));
}
Above: 12 cells = all chromatic degrees at the current octave. In Rooted mode, only the first N are emitted.
Below: the root degree across 9 octaves (0..8). Octave drives lightness 20%→80%.
Switch the FIXED/ROOTED pills to toggle the meaning of --music-count. Fixed (12) keeps C in the same 30° slice forever. Rooted (set count = scale length and rotate = root degree) puts the tonic at hue 0° and spreads the scale evenly around the wheel.
