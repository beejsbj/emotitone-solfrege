Depth and deletion test

Tests should cross the source-projection interface using real CodeMirror transactions: insert before an active note, delete or replace that note, undo/redo, replace generated source during playback, re-evaluate and reset location identity, stop/restart, and retain controlled-specimen progress. Verify rendered event identity and follow-scroll targets. Compare with installed native highlighting for unchanged surviving notes. A browser/audio check is still needed after implementation; the probe validates state transitions and decoration identity, not audible timing or rendered pixels.

Tradeoff. Tracking evaluation identity retains state across document edits and needs a clear replacement policy. Suppressing custom playback progress whenever source differs from its evaluated revision is a smaller safe correction, but loses live edit-following feedback. Mapping preserves the current interaction more closely. Choose this scope before adding support for more mini syntax; no new concrete interface is proposed here.

This complements PR #33 recording identity and PR #41 transport ownership. Musical context ownership concerns note interpretation; this finding concerns document revision and range identity.
